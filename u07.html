의문문·감탄문 · 비교 표현

핵심 문법핵심 어휘예문연습 문제 (4세트)
학습 목표
  • 의문사를 사용해 질문할 수 있다
  • 감탄문으로 감정을 표현할 수 있다
  • 비교급·최상급을 쓸 수 있다

핵심 문법

의문사 (교재 11장)

의문사에는 항상 강세 부호가 있고, 의문문·감탄문은 앞뒤에 부호(¿ ? / ¡ !)를 씁니다.

의문사뜻예
¿Qué?무엇¿Qué estudias?
¿Quién / Quiénes?누구¿Quién es ella?
¿Dónde? / ¿Adónde? / ¿De dónde?어디 / 어디로 / 어디 출신¿De dónde eres?
¿Cuándo?언제¿Cuándo es la fiesta?
¿Cómo?어떻게¿Cómo te llamas?
¿Cuánto/a/os/as?얼마나¿Cuántos años tienes?
¿Cuál / Cuáles?어느 것¿Cuál es tu número?
¿Por qué?왜 (답: porque)¿Por qué estudias español?

감탄문

¡Qué + 형용사/명사!: ¡Qué bonito! ¡Qué calor! / ¡Qué + 명사 + tan/más + 형용사!: ¡Qué día más bonito! / ¡Cuánto + 동사!: ¡Cuánto te quiero!

비교 (교재 12장)

우등 más ... que / 열등 menos ... que / 동등 tan + 형용사 + como, tanto/a/os/as + 명사 + como, 동사 + tanto como. 불규칙: mejor, peor, mayor, menor. 최상급: el/la más ... de, 절대최상급 -ísimo (guapísimo, facilísimo).

연습 문제

세트마다 채점하기를 누르거나, 아래의 전체 채점으로 한 번에 점수를 확인하세요. 빈칸은 강세 부호(á, é, ñ…)까지 맞아야 정답이며, 강세만 틀리면 0.5점입니다.
